# The independent Linux repeat

A GitHub-hosted Ubuntu 24.04 x86-64 runner collected 10 fresh native Harbor trials. It used the 2 seed labels selected from the 12-world source, not a new choice based on candidate outcomes. No model or paid container ran. No cell retried. [Source workflow run](https://github.com/PeterMakhnatch/harbor-seatlab/actions/runs/44549885787) · [two public data bundles](https://github.com/PeterMakhnatch/harbor-seatlab/releases/tag/panel-control-data-v1) · [machine receipt](results.json).

| Compared with the 10 corresponding original trials | Unchanged / examined |
| --- | ---: |
| Native joint-step schedules | 200 / 200 |
| Accepted role actions | 400 / 400 |
| Acknowledged private role views | 400 / 400 |
| Final per-role simulator returns, exact numeric equality | 20 / 20 |
| Registered case-by-criterion states | 18 / 18 |

All 10 native completion rewards are 1. All 10 trial UUIDs differ from the original 60. This result checks these programs on these seeds and runtime versions. It is not evidence of universal floating-point reproducibility. The CI job preserves missing observations. Its job exit indicates collection, not scientific agreement. Use `seatlab study recheck` to gate a candidate against a frozen source instead.
