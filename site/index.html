For Harbor task maintainers

Check your own agent or context change in CI

Keep Harbor as the runner and scorer. Give SeatLab the observations and actions your world recorded for each role. A final reward alone is not enough.

  1. Task owner: freeze your team configurations and select the native cases.
  2. Runner owner: collect independent workers and detect a return filed under the wrong job. Try the real control offline, without Docker or a model key.
  3. Eval Lab user: supply native trial IDs and count each shared reward once. Eval Lab is optional.

Two questions, kept apart

Score What did the team earn?

Harbor runs the world and verifies the shared result. A score tells you the outcome. It does not tell you which member did something different, or when.

Process How did the team get there?

SeatLab compares what each participant could see and what it did, in world order. It reports the first step where an input or action differs. It does not assign a reward to a future nobody ran.

Quickstart: check the numbers, then record your own task

  1. Verify the PettingZoo study

    Use Python 3.11 or later. No Docker, Harbor, or API key. The verifier checks the archive bytes and recomputes the 13 comparisons. It runs no code from the study.

    work=$(mktemp -d)
python3 -m venv "$work/venv"
r=https://github.com/PeterMakhnatch/harbor-seatlab/releases/download/v0.10.0
"$work/venv/bin/python" -m pip install --no-deps \
  "$r/harbor_seatlab-0.10.0-py3-none-any.whl"
curl -fsSL "$r/native-pettingzoo.tar.gz" -o "$work/native.tar.gz"
(cd "$work" && echo 'f15b5efb206a04d205c3ac6cda264d8e1847c34cee1ef20dc0c4213e4cc9779f  native.tar.gz' | shasum -a 256 -c -)
tar -xzf "$work/native.tar.gz" -C "$work"
"$work/venv/bin/seatlab" study verify "$work/study.json" \
  --expect-sha256 5100104afd2a2bd8194ee393e9cc68628046ccd750e7adfa04f7f843cc11afcf \
  --html "$work/report.html"

    Expect 8 complete matches and 5 changed steps. A verified report can still contain a failed policy or missing evidence.

  2. Record your own Harbor task

    Start from the 2-seat receipt board. Export each world-accepted actor receipt with 3 helpers. Pass the digest the actor returned; never recompute it.

    from seatlab.author import accepted_frame, decision_from_frame, episode_from_frames

    The offline path needs no Harbor installation. The native path uses Docker and no model key. See the author guide.

  3. Join the study to a native Harbor job

    The stock Eval Lab example reads 2 trials, 4 participant executions, and only 2 shared rewards. A withheld trial stays unknown.

    Use the pinned GitHub Action to require the verified study in another repository. This working consumer checks a genuine job and refuses a different trusted digest.

Proofs and limits

  • PettingZoo results and protocol native attempts, branches, Ubuntu repeat
  • Stable evidence note, v0.10.0 pinned digests for the calendar and team studies
  • Release v0.10.0 wheel, archives, and offline report files
  • Release v0.11.0 verified policy windows, speaker-listener games and stock Eval Lab join
  • Reproducing a decision does not make it a good decision.
  • The Hanabi data concern 2 scripted conventions, not the general strength of a model.
  • Simulated branches need an explicit deterministic simulator. They cannot forecast a human or a hosted model.
  • The 17 PettingZoo attempts are not 17 independent game seeds.
